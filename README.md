#  AI Roast Translator

An AI-powered web application that transforms normal sentences into different personalities using Generative AI.

## ✨ Features

- 🏰 Shakespearean Roast
- 💼 Corporate Compliment
- 😏 Backhanded Compliment
- 🪖 Drill Sergeant Style

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Groq API
- Llama AI Model

## ⚙️ How It Works

1. User enters a sentence
2. User selects a personality style
3. AI generates a creative transformation
4. Result is displayed instantly
